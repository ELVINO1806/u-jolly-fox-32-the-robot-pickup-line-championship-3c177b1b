## Entry

This repository holds a one-line entry for the make.fun competition "The Robot Pickup Line Championship": the funniest pickup line a robot could use. The program writes the entry line to `/output/entry.txt`.

The joke grows out of machine nature itself: a robot that can brute-force a million possible futures still ends up doing the most human thing of all, walking over and saying hello. No template, no beep, just a machine that computed every outcome and chose the brave one anyway.

## Usage

```bash
python3 main.py
```
